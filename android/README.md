# Android 多平台下载器

多平台下载器是一款 Android 应用，支持下载多个平台的视频、图片、音频和图文内容。

- 最低系统版本：Android 10
- 当前支持架构：`arm64-v8a`

[从 GitHub Releases 下载最新版 APK](https://github.com/Lyx10000/multi-platform-downloader-android/releases/latest)

## 安装

下载 Release 中的 APK 后，通过系统文件管理器打开安装。如果系统阻止侧载，请按照系统提示允许当前安装来源安装未知应用。

使用本项目正式签名的旧版本可以覆盖升级，并保留任务记录、设置和平台登录状态。其他来源或使用不同证书签名的安装包无法直接覆盖。

## 基本使用

1. 复制受支持平台的作品链接或分享文本。
2. 打开应用并粘贴内容，点击“解析作品”。
3. 选择清晰度、保存模式和是否归档作者。
4. 开始下载，在任务页查看进度，在本地下载页管理文件。

首页可以切换到“查找作者”，通过受支持平台的作者主页链接建立作者库并选择公开作品批量下载。小红书目前仅支持单个作品下载。

## 下载与文件管理

- “任务”页面显示正在准备、等待或下载中的任务。
- 下载完成的内容进入“本地下载”，并按独立作品或作者归类。
- 支持查看下载进度、实时速度、文件大小和设备运行状态。
- 支持图片、视频和音频预览。
- 支持单选或多选分享文件。
- 支持重新下载、批量重试、删除任务以及同步删除下载文件。
- 支持在应用内复制、移动、重命名和删除文件。
- 作者本地作品支持按下载时间、发布时间和文件大小排序。

知乎文章、回答和想法会保存为 Markdown，相关图片和视频保存在同一任务目录中，并可通过应用内阅读器查看。

## 保存位置

默认下载目录：

```text
内部存储/Download/MultiPlatformDownloader/
```

可以在设置中通过系统目录选择器指定其他保存位置。

诊断日志默认保存在应用私有目录。手动导出后，ZIP 文件会保存到：

```text
内部存储/Download/MultiPlatformDownloader/diagnostics/
```

旧版本创建的 `Download/DouyinDownloader/` 目录仍可继续读取和管理。

## 本地构建

准备 Android SDK、JDK 17 和可用的 Android 构建环境，然后运行：

```bash
cd android
./gradlew testDebugUnitTest assembleDebug
```

构建未签名的 release APK：

```bash
./gradlew assembleRelease
```

`assembleDebug` 使用调试证书签名，仅适合开发测试。仓库不包含正式签名私钥，发布 release APK 前需要使用自己的证书完成签名。

源码命名空间为 `com.local.multiplatformdownloader`。为兼容已经发布的版本，Android `applicationId` 仍保留为 `com.local.douyindownloader`；修改该值会导致系统将 APK 识别为另一个应用，并且无法直接继承旧版数据。

## 已知限制

- 可下载内容和清晰度取决于平台当前返回结果、作品权限及登录状态。
- 平台接口或页面发生变化后，部分解析功能可能需要更新应用才能恢复。
- 私密、付费、会员专享、已删除或无权访问的内容可能无法下载。
- 频繁解析或批量请求可能触发平台风控，请按照应用提示等待后重试。
- 图片会优先选择没有明确水印特征的高质量候选，但平台只提供带水印资源时无法保证去除水印。
- H.265 视频可能无法在部分旧播放器中播放，可以选择相同分辨率的 H.264 档位。
- 小红书作者主页和批量下载暂不支持，单作品下载不受影响。
- B站当前支持普通投稿和多 P 视频，不包含番剧、直播、动态及付费内容。
- Instagram、X 及其他平台的可访问内容受账号状态和平台风控限制。
