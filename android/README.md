# Android 聚合下载器

面向 Android 手机侧载使用，最低 Android 10，
APK 只包含 `arm64-v8a`。

## 安装

将 release APK 复制到手机后点击安装。如果 ColorOS 阻止安装，请在系统提示中仅对
当前文件管理器允许“安装未知应用”。覆盖安装后，历史、设置和 WebView 登录态会
保留。

首次使用：

1. 打开应用，允许通知，以便后台下载显示进度。
2. 粘贴抖音、小红书或知乎分享文本并点击“解析作品”。
3. 应用会在进度界面后方建立对应平台的解析环境，不会显示平台网页。
4. 选择清晰度和保存模式后开始下载。

抖音会复用已有 Cookie；小红书和知乎会先尝试匿名解析。Cookie 缺失、过期或接口触发风控时，
应用才会在后台刷新对应平台的 WebView 环境。知乎图文的普通请求被拒绝时，隐藏 WebView 会
直接加载目标内容并提取页面数据，不会显示知乎界面。后台刷新最长等待 15 秒，之后会继续解析并
给出明确结果，不会无限停留在准备界面。也可以在设置中分别打开各平台的登录环境。

清晰度列表优先显示接口或 CDN 返回的精确文件大小；无法取得精确值时显示根据码率和
时长计算的“约”值，仍无法计算时明确显示“大小未知”，不会再显示 0 MB。

也可以在抖音、小红书或知乎的分享面板中选择本应用。分享进入后应用会自动开始解析。
首页的“平台登录状态”会根据各平台明确的登录 Cookie 名显示是否检测到凭据，点击状态可打开全屏登录环境。未登录时部分内容可能解析失败；凭据过期或触发风控时仍可能需要重新登录。
下载完成后，任务页会先列出成品视频、视频轨、音频轨和图片。可以单选或多选同一类
文件，再通过系统分享面板发送到 QQ、微信、邮件等支持对应格式的应用；多图任务支持
一键全选图片。Markdown 作为普通文件分享；为避免接收应用误判，不会把不同媒体类别混在
同一次分享请求中。

知乎文章、指定回答和想法会把正文保存为 Markdown，图片和知乎内嵌视频放入任务目录下的
`media/` 子目录。在任务的文件管理中点击 Markdown 会进入内置阅读器，可直接显示已下载图片，避免 Android 第三方 Markdown 应用无权读取同级 `media/` 目录的问题。单个媒体失效时仍会保留 Markdown 和远程链接，并在任务状态中显示未下载
项数。独立知乎视频沿用清晰度选择和四种音视频保存模式。

任务卡的“管理文件”会进入应用内文件管理页面。长按文件后可以多选分享、复制、移动或
删除，单选时还可以重命名；复制和移动通过系统目录选择器指定目标，但文件操作由应用执行，
不依赖厂商文件管理器是否提供编辑按钮。复制出的副本不会加入任务记录，移动和重命名会
同步更新任务 URI。右上角仍可用系统文件管理器打开最初下载目录。

默认输出目录：

```text
内部存储/Download/DouyinDownloader/
```

设置中可以通过系统目录选择器改用其他目录。诊断日志默认位于应用私有目录，只有
点击“导出 ZIP”后才会写入公共下载目录。

任务页会检查已下载文件是否仍然存在。部分文件被外部删除时任务显示橙色，全部文件
被删除时显示灰色；点击异常任务可以重新解析作品并下载。删除任务时可以选择是否同步
删除下载内容，应用只删除该任务登记的文件，不会递归删除后来放入任务目录的其他文件。
默认目录的空文件夹清理需要在设置中授予“所有文件访问”，普通下载不依赖该权限。

## 本地构建

```bash
cd android
./gradlew testDebugUnitTest assembleDebug
./gradlew assembleRelease
```

本项目所在的 ARM64 Termux 环境需要 ARM64 原生 AAPT2。当前构建配置指向：

```text
/data/data/com.termux/files/usr/bin/aapt2
```

在普通 x86-64 Linux/Android Studio 中构建时，应删除 `gradle.properties` 中的
`android.aapt2FromMavenOverride`，使用 Android Gradle Plugin 自动下载的 AAPT2。

## 已知边界

- 抖音、小红书和知乎都没有面向此用途的公开稳定下载 API，Cookie、签名或字段变化后可能需要
  更新 APK。
- 首次解析或出现登录/风控提示时，可在设置中打开对应平台的全屏登录环境。页面支持缩放，
  方便完成登录或验证操作。
- H.265 是最高档时，旧播放器可能不兼容，可手动选择相同分辨率的 H.264。
- 小红书只解析分享链接当前能够访问到的公开图片和直连视频档位；失效的 `xsec_token`、
  私密/已删除笔记以及只返回 HLS 的视频可能无法下载。
- 知乎第一版支持文章、指定回答、想法和独立视频；只有问题 ID 的链接、盐选、付费、私密及
  已删除内容不支持，外部平台嵌入视频只在 Markdown 中保留链接。
- APK 中的媒体处理使用 Android MediaExtractor/MediaMuxer，只做编码轨复制，不转码。
