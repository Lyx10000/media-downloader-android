# Android 统一媒体预览播放设计

日期：2026-09-04

## 背景

任务页面已经支持图片缩略图、视频帧缩略图和纯音频播放，但视频不能在应用内播放。现有音频预览使用平台 `MediaPlayer`，只接受单个音频 URI；视频下载则可能产生三种输出：带内置音频的视频、独立视频与音频轨、以及已经合成的 MP4。

为了让所有下载模式都能获得一致预览，需要把音频专用播放器升级成统一媒体播放子系统。分离轨道不能用两个播放器手工轮询对时，否则容易发生启动偏移和长期漂移；应交给同一个 Media3 ExoPlayer 时间线处理。

## 目标

- 视频可以直接在展开的任务卡预览区域播放。
- 支持播放/暂停、点击或拖动进度、静音和全屏。
- 已合成或原本带音频的视频直接播放。
- 分离视频轨和音频轨在内存中同步播放，不生成临时合成文件。
- 只有视频轨时正常提供无声预览，并明确显示无声状态。
- 音频与视频共用唯一播放器，任意时刻只播放一个媒体。
- 切任务、收起预览、滚出组合范围、离开任务页、退后台或锁屏时停止并释放。
- 退出全屏后返回卡片并保留当前位置，但保持暂停。
- 兼容已有任务和旧输出记录，不要求重新下载。
- 播放错误写入诊断日志，不改变下载任务状态。

## 非目标

- 不自动播放，不循环播放，不在后台继续播放。
- 不实现播放列表、倍速、画中画、投屏、字幕或手势调节音量/亮度。
- 不为预览重新编码、压缩或永久合成文件。
- 不改变下载模式、源文件或现有分享行为。
- 不加入华为系专用媒体兼容代码。

## 方案选择

### 采用：单实例 Media3 ExoPlayer

应用使用一个 ExoPlayer 处理音频、普通视频和分离音视频。分离轨道通过 `MergingMediaSource` 组合，启用时间偏移调整并裁剪到较短轨道。视频表面使用 Media3 的 Compose `PlayerSurface`，控制区继续使用应用现有 Material 3 组件。

选择此方案的原因：

- 音频和视频天然共享播放互斥、音频焦点和生命周期。
- 分离轨道进入同一播放器时间线，不需要两个播放器持续校时。
- 卡片与全屏可以复用同一个播放器和播放位置。
- 不写临时文件，开始播放更快，也不会额外占用公共存储。

### 不采用：双播放器手工同步

分别播放视频和音频，定时比较位置并 seek 校正。实现表面简单，但启动时序、缓冲、seek 和设备负载都会造成音画抖动或漂移，不适合保留。

### 不采用：预览前临时合成

调用现有媒体处理器生成临时 MP4 后再播放。同步可靠，但每次首次预览都可能等待较长时间，还会产生大量缓存写入，违背即时预览目标。

## 播放源解析

`TaskPreviewResolver` 从仍可读取的任务输出中生成结构化预览源：

- `ImagePreviewSource`：第一张可用图片和可用图片数量。
- `AudioPreviewSource`：一个音频 URI。
- `VideoPreviewSource`：视频 URI、可选音频 URI、来源类型和备用策略。

视频候选不能只按列表顺序选择。解析器在后台使用媒体轨道检查器读取本地内容 URI 的轨道 MIME：

1. 优先选择同时包含视频轨和音频轨的文件，作为合成/内置音频视频直接播放。
2. 如果没有完整视频，选择视频轨文件，并匹配任务内可用的独立音频文件。
3. 如果独立音频不存在，返回无声视频源。

文件名 `video_1.mp4`、`video_1_video.mp4` 和 `video_1_audio.m4a` 只作为旧文件或轨道检查失败时的兼容提示，不作为唯一判断依据。图文作品中同时存在图片与 BGM 时仍优先显示图片，不自动播放 BGM。

## 组件边界

### MediaTrackInspector

负责在 IO 线程检查内容 URI 是否可读，以及包含视频轨、音频轨或两者。它不创建播放器、不修改文件。单次展开只检查当前任务的少量候选，并对相同 URI 的结果做页面生命周期内缓存。

### MediaPreviewCoordinator

替换现有 `AudioPreviewCoordinator`，持有全应用唯一 ExoPlayer，并暴露只读状态：

- 当前任务和播放源标识。
- 媒体类型、准备/播放/暂停/结束/错误状态。
- 当前位置、总时长、是否静音和视频宽高比。
- 当前 ExoPlayer 实例，仅供被选中的视频表面绑定。

协调器负责准备媒体源、播放、暂停、seek、静音、音频焦点、进度更新和释放。新任务开始播放前先释放旧源。音频预览也迁移到该协调器，不再保留平台 `MediaPlayer` 路径。

### TaskPreviewResolver

把任务输出、可读性和轨道检查结果转换成预览源。它负责选择“完整视频、分离轨道或无声视频”，但不控制播放状态。

### TaskPreview UI

图片预览维持现状。视频预览分为：

- 未播放：显示现有视频帧缩略图和播放按钮。
- 准备中：保持固定 16:9 容器并显示短时进度提示。
- 播放中/暂停：显示 `PlayerSurface`、中央播放/暂停按钮、进度 Slider、时间、静音和全屏按钮。

控制按钮保持至少约 48dp 触控区域，图标都有语义描述。进度 Slider 的点击与拖动行为和音频保持一致。

### 全屏容器

全屏使用 Compose 全屏 Dialog/覆盖层并复用同一播放器，不创建第二个 ExoPlayer。进入全屏不改变播放状态；退出全屏先暂停，再将同一位置交还卡片。返回键等同退出全屏。界面不强制旋转，遵循设备当前方向和系统自动旋转设置。

## 媒体源构造

- 完整视频：`ProgressiveMediaSource(videoUri)`。
- 纯音频：`ProgressiveMediaSource(audioUri)`。
- 分离轨道：分别创建视频和音频 `ProgressiveMediaSource`，再使用 `MergingMediaSource(adjustPeriodTimeOffsets = true, clipDurations = true)` 合并。
- 无声视频：只使用视频源，同时在控制区显示“无独立音频”。

如果合并源因时间线不兼容而失败，协调器自动降级为无声视频并显示“音频轨无法同步，已播放画面”，同时记录失败原因。该降级不会生成文件，也不会标记任务失败。

## 生命周期与互斥

1. 用户展开视频任务时只解析预览源，不自动创建或播放媒体。
2. 用户点击播放后，协调器停止旧媒体、准备当前源并开始播放。
3. 播放音频会停止视频；播放视频会停止音频。
4. 展开另一个任务会收起当前任务并释放播放器。
5. 当前卡片离开 Compose 组合范围时停止播放，防止视频在列表外继续出声。
6. 收起预览、删除任务、离开任务页、Activity `onStop` 或 ViewModel 清理时释放播放器。
7. 退出全屏时记录当前位置、暂停播放并返回卡片；用户需要再次点击才能继续。

播放器状态只保存在内存，不写数据库。应用进程重建后从未播放状态开始。

## 错误处理与日志

用户可见错误使用简短提示，并保留重试播放入口：

- 文件不可读：提示文件可能已移动或删除。
- 编码不支持：提示当前设备无法解码该视频或音频。
- 分离轨道无法合并：自动无声播放视频，并显示降级说明。
- 视频表面异常：释放播放器并恢复缩略图，不能导致任务页崩溃。

诊断日志记录：

- 预览源类型：完整视频、分离轨道、无声视频或纯音频。
- URI authority、MIME 和轨道类型，不记录完整文件路径或敏感 URL 参数。
- ExoPlayer 状态转换、媒体错误代码、解码器名称和降级原因。
- 全屏进入/退出、seek、静音、页面停止和资源释放。

日志不高频记录每次进度刷新。

## 测试策略

### 单元测试

- 完整视频优先于分离视频轨。
- 分离视频与音频正确配对。
- 没有音频时生成无声视频源。
- 图片+BGM 仍选择图片，纯音频仍选择音频。
- 新播放请求替换旧任务，页面停止会清空播放状态。
- 合并源失败后只降级视频，不改变任务状态。
- 点击/拖动 seek、播放结束重播和静音状态转换正确。

### Compose/UI 测试

- 缩略图点击后切换为播放器表面。
- 卡片控制区的播放、暂停、进度、静音和全屏状态正确。
- 全屏返回后卡片位置保留且处于暂停。
- 同时只有当前展开任务显示活动播放器。
- 错误和无声降级不是仅靠颜色表达。

### 构建与设备验收

- 全量单元测试、主代码 Lint 和 Release 构建通过。
- 一加 13T 验证合成视频、分离轨道、纯视频和纯音频四类任务。
- 验证快速切换任务、频繁 seek、锁屏、切后台、旋转和全屏返回。
- vivo Y70s 后续通过日志确认硬件解码和 Surface 行为；没有实机时不阻断构建。

## 发布与兼容

- 新版递增 `versionCode` 和 `versionName`，使用现有相同证书签名，支持覆盖安装。
- APK 继续只构建 ARM64，并复制到 `/mnt/Android/douyinDownload`。
- 源码推送 GitHub 主分支，不创建 GitHub Release。
- 旧任务无需迁移数据库；预览源完全从现有输出记录和本地媒体轨道推导。

## 完成标准

- 合成视频和分离音视频都能在任务卡内带声音预览。
- 音频、视频和全屏始终复用唯一播放器，不发生并发出声。
- 进度点击/拖动、静音、全屏和退出暂停符合设计。
- 分离轨道不产生临时文件，无法同步时安全降级为无声视频。
- 离开播放上下文后播放器资源被释放，返回不自动续播。
- 播放问题可通过本地诊断日志定位，且不影响下载任务状态。
