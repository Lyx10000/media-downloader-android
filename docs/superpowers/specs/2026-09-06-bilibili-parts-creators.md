# B站分P与作者目录

用户已选择：整个稿件一张卡，进入后独立管理各P。延续无需反复批准的开发偏好。

- 多P目录来自稿件详情的 pages，不在初次解析时请求每P播放地址。默认选链接指定P（无参数为P1），可勾选/全选。
- 每P保留真实任务与 BV:cid 身份，列表按BV聚合展示；进入分P页复用普通任务的进度、预览、重试、删除。全部内容删除仍需原确认。
- 子任务独立文件夹，不互相覆盖；创建其他P时保存待解析规格，实际下载前顺序获取新地址，核对cid。不中途替换成别的P。
- B站作者模式支持准确UID和 space.bilibili.com 主页，读取公开资料及投稿分页。原接口流程参考BiliDownload，WBI协议独立用Kotlin实现，不引入Python。
- 作者批量按稿件勾选，统一设置里可选择全部P或仅P1，默认全部P且明确提示。每稿件内部仍逐P任务，不增加下载并发。
- 作者本地记录按BV关联所有P；批量删除/重试覆盖该稿件的相应子任务，失败记录不丢失。
- 远端访问受限时明确失败、停止重试，不清除本地记录，不判断为账号注销。现有CDN请求配置保留。
- 无数据库破坏性迁移；新增可选JSON字段兼容旧任务。版本保持1.6.2/42，无R8、不push/release。
- 验证：WBI签名、UID边界、分P身份/选择/序列化/分组、已有下载回归；低频匿名作者列表探测，最后编译与原证书签名。

实现顺序：解析与模型 → 作者接口 → 子任务准备 → 单条/作者UI → 针对性测试与构建。
本次没有可用的writing-plans技能，以上实施顺序由主代理直接维护。

## 实现与验证记录

- 子任务 JSON 仅保存自身分P描述，避免完整目录随每个P重复保存造成平方级增长；真实下载前检查 BV:cid。
- 作者公开列表以BV为作品身份，本地下载关联全部cid。已存在任务复用安全重新下载，不先删除文件；缺少的P才新建。
- 保留原下载并发数。分P解析串行限速；作者接口遇403/412/429或业务风控暂停一分钟，用户手动再试。
