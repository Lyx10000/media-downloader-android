# Android 任务预览与文件夹导航设计

日期：2026-09-04

## 背景

任务页面当前只展示下载状态、输出信息以及分享、取消、删除等操作。用户需要在不离开任务列表的情况下确认图片、视频或纯音频内容，并希望能够从任务卡直接进入该任务的下载文件夹。

现有输出记录已经保存 `uri`、文件名、MIME 类型和大小，可以作为预览与目录定位的数据来源；应用已经使用 Jetpack Compose Material 3 和 Coil，但尚未建立音频播放器及其页面生命周期管理。Android 也没有一个能保证所有厂商文件管理器精确进入任意目录的统一 Intent，因此文件夹导航必须采用能力探测与安全降级，而不是按机型硬编码包名。

## 目标

- 每个有可用输出的任务卡提供可展开、可收起的预览区域。
- 同一时间最多展开一个任务的预览，避免长列表被大量媒体占据。
- 图片显示缩略预览，视频显示视频帧缩略图，纯音频提供播放、暂停和进度控制。
- 同一时间只允许播放一个音频；播放下一个时停止并释放上一个。
- 离开任务页面时暂停并释放播放器，返回页面后不自动续播。
- 进度条支持拖动以及点击目标位置跳转。
- 每个有效任务提供“文件夹”按钮，优先进入任务目录，失败时逐级降级。
- 目录打开失败不导致崩溃，并留下足够的本地诊断信息以便后续适配。
- 兼容主流 Android 10 及以上设备，但不为华为、荣耀、EMUI 或 HarmonyOS 增加专用适配。

## 非目标

- 不在任务列表内播放视频，也不实现全屏图片或视频浏览器。
- 不自动播放音频，不在离开任务页面后后台播放。
- 不同时展开多个任务预览，不同时维护多个播放器。
- 不为特定厂商硬编码第三方文件管理器包名或非公开 Activity。
- 不承诺所有厂商文件管理器都能精确进入任务目录。
- 不适配华为系设备及其文件管理器私有行为。

## 交互设计

### 预览入口

任务卡右下角增加“预览”操作。点击后在当前卡片底部展开预览，再次点击收起。展开另一张任务卡时，先收起当前卡片并停止其音频。

只有至少存在一个可读取输出的任务才显示预览入口。任务文件缺失时沿用现有灰色状态与重新下载/删除提示，不显示不可用的预览控件。

多图片任务默认显示第一张可用图片作为封面，并提示输出数量。预览区域不承担多选分享；现有分享按钮继续处理多文件选择与分享。

### 图片和视频预览

- 图片：使用内容 URI 加载第一张可用图片，按卡片宽度约束并保持原始宽高比，设置合理最大高度。
- 视频：读取第一段可用视频的帧作为缩略图，叠加视频标识；点击缩略图不在卡片内播放。
- 加载中显示尺寸稳定的占位区域，避免列表跳动。
- 解码失败时显示“无法生成预览”，但保留分享、文件夹和删除等操作。

### 纯音频预览

当任务不存在图片和视频、但存在可用音频输出时，展开区域显示：

- 播放/暂停按钮。
- 当前播放时间和总时长。
- Material 3 `Slider` 进度条。

Slider 的拖动与点击都更新目标进度。拖动期间界面显示用户选择的位置，松手后执行一次 seek，避免频繁 seek 引发卡顿。播放器准备期间禁用播放和进度操作，并显示简短状态。

### 文件夹入口

任务卡提供“文件夹”按钮。点击后按以下顺序执行：

1. 如果任务保存在用户选择的 SAF 目录，使用持久化 Tree URI 推导任务子目录，并通过系统文档界面定位。
2. 如果任务保存在默认公共下载目录，构造任务目录的文档 URI，尝试由系统或已安装文件管理器处理目录 Intent。
3. 精确目录无法处理时，使用 `ACTION_OPEN_DOCUMENT_TREE` 和 `DocumentsContract.EXTRA_INITIAL_URI` 打开系统 DocumentsUI，初始位置尽量设为任务目录。
4. 任务目录无法解析时退到应用下载根目录。
5. 所有处理器均不可用时显示“无法打开文件夹”，不崩溃。

Android 11 及以上对系统文件选择器中的根目录和 Download 根目录授权有限制；文件夹按钮只用于导航，不依赖用户再次授予 Download 根目录权限。

## 状态与组件边界

### TasksViewModel

持有列表级 UI 状态：

- 当前展开的任务 ID。
- 当前音频播放器对应的任务 ID。
- 播放状态、当前位置、时长和准备/错误状态。

展开状态不写入数据库。离开任务页面或 ViewModel 被清理时，调用播放器协调器停止并释放资源。

### AudioPreviewCoordinator

新增单实例页面级播放器协调器，封装 Android 媒体播放实现。它负责：

- 根据内容 URI 准备音频。
- 保证新播放请求先停止并释放旧播放器。
- 提供播放、暂停、seek、时长和进度状态流。
- 页面停止时释放播放器。
- 捕获无法读取、格式不支持、媒体损坏和播放器状态错误。

播放器不会作为应用级后台服务存在，也不申请音频后台播放能力。音频焦点丢失时暂停；返回任务页面后保持停止状态。

### TaskPreviewResolver

根据任务输出的真实 MIME 类型与可读性选择预览类型：图片优先，其次视频，最后纯音频。它只返回仍然存在且可读取的输出 URI，不根据文件扩展名伪造 MIME 类型。

### TaskFolderNavigator

统一负责目录 URI 推导、Intent 构造、运行时处理器检查、启动和降级。Compose UI 不直接拼接厂商包名或捕获零散 Activity 异常。

导航器在每次启动前使用 `PackageManager` 检查处理能力，并捕获 `ActivityNotFoundException`、`SecurityException` 和无效 URI。所有失败均继续下一层方案。

## 生命周期与数据流

1. 用户展开任务 A，预览解析器选择可用媒体。
2. 如果 A 是纯音频，只有用户点击播放后才创建播放器。
3. 用户展开或播放任务 B，协调器停止并释放 A，随后准备 B。
4. 用户收起当前卡片，音频立即停止并释放。
5. 用户切换底部导航、离开任务页面或 Activity 进入后台，播放器停止并释放。
6. 用户返回任务页面，卡片可以保持或重新获得普通列表状态，但音频绝不自动恢复播放。

播放器进度只保存在内存。任务记录、下载状态和输出文件不因预览操作发生变化。

## 设备兼容范围

应用当前最低版本为 Android 10（API 29），因此标准实现面向 Android 10 及以上设备：

- Google Pixel 与 AOSP 风格系统。
- 一加、OPPO、realme 的 ColorOS/OxygenOS 系列；一加 13T 作为优先验证设备。
- vivo、iQOO 的 Funtouch OS/OriginOS 系列；vivo Y70s 作为重点日志验证设备。
- 小米、Redmi、POCO 的 MIUI/HyperOS 系列。
- 三星 One UI。
- Motorola/Lenovo、Sony、ASUS、Nothing 等提供标准 DocumentsProvider 的设备。

上述“兼容”表示使用公开 Android API 可以打开文件管理或系统文档界面；精确落入任务目录仍取决于设备上的处理器实现。华为、荣耀、EMUI、HarmonyOS 不进入专项兼容和验收范围；如果标准 Android 路径偶然可用，可以正常工作，但不承诺、不硬编码也不专项修复其私有行为。

## 错误处理与日志

预览和目录导航的错误不能改变任务下载状态。用户看到的是短而明确的提示，详细原因写入本地诊断日志。

目录日志包含：

- 制造商、型号、Android API 版本。
- 任务存储模式和目标目录类型，不记录用户目录中的无关文件名。
- 尝试的导航策略和 URI authority。
- 实际解析到的处理器包名。
- 成功、降级层级和异常类型。

音频日志包含：准备、开始、暂停、seek、停止、释放和错误阶段，但不高频记录每次进度刷新。日志不得记录 Cookie、下载鉴权参数或完整带敏感查询参数的远程 URL。

## 测试策略

### 单元测试

- 输出包含图片、视频、音频和混合文件时预览类型选择正确。
- 缺失或不可读文件不会进入预览候选。
- 展开新任务会收起旧任务并触发停止播放。
- 目录导航按直接目录、DocumentsUI、下载根目录顺序降级。
- 不存在 Activity、权限拒绝和非法 URI 均转换为可控结果。

### Compose/UI 测试

- 预览按钮可展开和收起，且一次只展开一张卡片。
- 音频播放、暂停、点击跳转和拖动跳转状态正确。
- 页面离开后停止，返回后不自动播放。
- 文件缺失任务不显示可操作的预览入口。
- 预览失败不影响分享、文件夹和删除操作。

### 设备验收

- 一加 13T：默认目录、自定义 SAF 目录、精确定位和全部降级路径。
- vivo Y70s：验证 Android 10 下预览、音频生命周期、目录处理器和失败日志。
- 至少一台接近 AOSP 的 Android 设备或模拟器：验证标准 DocumentsUI 行为。
- 不将华为系设备列为发布阻断项。

## 完成标准

- 任务卡可以稳定展开图片、视频或纯音频预览，不影响现有下载、分享、删除与滚动行为。
- 任意时刻最多存在一个音频播放器，离开页面后没有声音且返回不续播。
- 音频进度条同时支持点击和拖动跳转。
- 文件夹按钮优先定位任务目录，失败时可安全降级且不闪退。
- 一加 13T 和 vivo Y70s 的后续实机反馈可以通过日志定位到具体导航策略和处理器。
- 华为系不包含专用代码、专用测试或兼容承诺。
