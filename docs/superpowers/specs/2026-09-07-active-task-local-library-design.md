# 活动任务队列与本地下载内容库设计

日期：2026-09-07  
状态：已确认，待实现

## 1. 目标

将当前混合了下载状态、历史任务和作者收藏的页面拆分为两个职责清晰的模型：

- **任务**：只展示仍需处理的活动下载。
- **本地下载**：管理已经落盘或部分落盘、可实际使用的内容。

作者收藏、公开作品和作者本地内容统一归入“本地下载”的作者视图。完成任务不再作为历史卡片留在任务页，也不向用户显示批次编号。

## 2. 底部导航与页面职责

底部导航调整为：

1. 首页
2. 任务
3. 本地下载
4. 诊断
5. 设置

页面职责：

- 首页：输入作品或作者链接、解析内容、发起下载、展示平台登录状态。
- 任务：活动队列、实时进度、速度、暂停、继续、取消、重试和删除。
- 本地下载：预览、分享、打开文件夹、重新下载、删除文件及作者内容管理。
- 诊断：日志查看和导出。
- 设置：保存路径、应用更新和通用配置。

## 3. 任务页

### 3.1 展示范围

任务页只展示以下状态：

- 准备中
- 等待中
- 下载中
- 已暂停
- 等待风控冷却
- 失败或部分失败且仍需用户处理

下载成功的任务从任务页消失。取消或删除的任务也不在任务页保留历史卡片。内部任务 UUID、下载记录和日志关联仍然保留，用户界面不显示任务编号或批次编号。

空状态只显示“暂无进行中的任务”，不显示进度圈或跳转按钮。

### 3.2 统一任务流

任务页不再使用独立任务/作者两个顶级标签，而是使用统一任务流，并提供以下筛选：

- 全部
- 独立作品
- 作者任务
- 平台
- 状态

运行、等待、暂停和风控冷却中的项目优先显示。

### 3.3 作者任务聚合

作者是否收藏以“平台＋作者唯一账号 ID”为准，不能使用可变化或可重复的昵称判断。

- 已收藏作者的所有同时活动任务聚合为一张作者任务卡片。
- 多次发起的下载只要活动时间重叠，就加入同一张作者卡片。
- 未收藏作者的下载显示为独立任务卡片。
- 作者卡片最后一个任务完成、取消或删除后自动消失；失败、暂停或等待中的子任务会使卡片继续保留。

作者任务卡片显示：

- 作者头像
- 平台标签
- 作者名称
- 活动作品数量
- 总体进度
- 当前总下载速度
- 本轮活动期间的峰值总下载速度

点击作者卡片进入子任务列表。子任务显示缩略图、作品文案、状态、文件进度、下载速度和失败原因，并支持单项或批量暂停、继续、取消、重试和删除。

任务页只保留用于识别作品的缩略图，不提供完整图片、视频或音频预览。

### 3.4 顶部运行状态

任务页顶部使用紧凑状态面板显示：

- 当前总下载速度
- 活动任务数量
- 应用 CPU 负载
- 系统热状态（正常、轻微、较高、严重）
- 受风控平台及剩余冷却时间

不显示不可靠的精确芯片温度。应用 CPU 负载与系统热状态需要使用准确名称，避免让用户误认为是整机 CPU 利用率或真实摄氏温度。

精确风控倒计时只在顶部显示；受影响的卡片和子任务仅显示“等待风控冷却”。风控冷却只限制该平台的新解析、批量准备或需要平台接口的请求。已经取得有效 CDN 地址的文件传输不得被平台解析风控门禁阻塞。

### 3.5 完成反馈

任务完成时：

- 从任务页移除活动投影。
- 显示“下载完成，已移至本地下载”的短暂提示。
- 提示提供“查看”操作，直接打开对应本地内容。
- 首页“最近任务已完成”同样跳转到本地内容，而不是已经消失的任务卡片。

## 4. 本地下载页

本地下载分为两个标签：

1. 独立作品
2. 作者

两个标签均支持按平台筛选。作者标签中的收藏作者和已归档作者都遵循筛选条件。

### 4.1 独立作品

未收藏作者的成功下载进入独立作品。独立作品支持：

- 图片多图预览
- 视频预览、全屏播放和续播
- 音频播放、暂停、拖动和点击进度跳转
- Markdown、知乎评论和问题归档阅读
- 分享
- 打开文件夹
- 重新下载
- 删除文件或仅删除记录
- 文件缺失检测
- 多选操作

### 4.2 作者

作者列表包含：

- 收藏作者
- 已归档作者

作者卡片显示头像、平台、名称、本地作品数量和本地文件总大小，不显示实时下载进度、当前速度、成功数或失败数。

作者详情保留三个区域：

- Profile
- 公开作品
- 本地下载

公开作品只显示“已下载、下载中、失败、远端不可用”等简要状态；查看实时进度时跳转到任务页对应任务。作者本地下载承担完整预览和文件操作。

账号注销、主页失效、用户手动归档，或取消收藏但仍存在本地作品的作者进入已归档作者。已归档作者继续保留本地内容。没有本地作品的作者取消收藏时可以直接移除。

### 4.3 失败和部分文件

- 完全失败且没有任何可用文件的任务只留在任务页，不进入本地下载。
- 部分成功且存在可用文件时，任务页继续显示未完成状态，本地下载同时显示可用内容并标注“内容不完整”。
- 重试补齐后自动移除“不完整”标记。
- 删除失败任务时，如果存在部分文件，必须让用户选择是否同步删除文件。

完成任务从任务页消失只是删除活动状态投影，不能删除底层内容记录。预览、分享、重新下载、文件缺失检测和日志仍使用同一内部任务记录。

## 5. 下载目录与作者收藏

### 5.1 新下载归类

下载开始前判断作者收藏状态，并锁定本次任务的目标目录：

- 已收藏作者：直接写入稳定作者目录。
- 未收藏作者：写入独立作品目录。

作者存在活动下载时，禁止收藏和取消收藏；相关按钮置灰并提示“该作者有任务正在下载，完成或取消后可操作”。这样避免下载过程中切换目标目录。

建议目录结构：

```text
下载根目录/
├── 作者/
│   └── 平台/
│       └── 作者名称_[稳定账号ID]/
│           └── 作品目录/
└── 独立作品/
    └── 平台/
        └── 作品目录/
```

作者改名只更新应用内资料，默认不自动重命名已有作者目录。目录必须包含稳定账号 ID，避免重名和改名冲突。

### 5.2 收藏作者时整理独立作品

收藏作者时检索该作者已有的独立作品，并执行可恢复、可校验的迁移：

1. 使用平台和作者唯一 ID 匹配作品。
2. 暂时锁定该作者的下载和收藏状态操作。
3. 创建目标作者目录。
4. 同一文件系统优先直接移动完整作品文件夹。
5. SAF 或跨存储位置使用复制、校验、更新记录、删除来源的流程。
6. 校验目标文件数量、总字节数和可读性。
7. 更新数据库中的 URI、预览、分享和归类信息。
8. 只有目标完整可用后才删除原独立作品文件夹。

迁移中断后必须能够继续。失败时保留原文件，显示具体失败项，不允许静默删除或覆盖。同名目标使用作品 ID 区分。

### 5.3 旧版本数据迁移

升级时自动完成数据库逻辑归类，使现有内容立即出现在正确的独立作品或作者视图中。

- 同一文件系统能够直接移动的旧文件可自动整理。
- SAF、跨存储或需要复制后删除的内容不在升级启动阶段自动复制。
- 对此类作者显示“文件待整理”，由用户查看空间需求后启动整理。
- 新版本创建的任务从开始就使用正确目录。

## 6. 状态与数据投影

同一内部记录可以生成两个不同用途的界面投影：

```text
TaskRecord / DownloadRecord
├── 活动状态投影：未完成时出现在任务页
└── 本地内容投影：存在可用文件时出现在本地下载
```

活动投影与本地投影允许在“部分成功”状态下同时存在。任务完成后只移除活动投影。本地文件被外部删除后，本地投影置灰并提供重新下载或删除记录，不能将记录误判为活动任务。

作者聚合卡片应由当前活动记录动态计算，而不是创建永久批次实体。内部仍保留 WorkManager ID、任务 UUID、作者稳定键和日志关联，用于恢复、取消和诊断。

## 7. 实现约束

- 不重写平台解析器、CDN 下载器或音视频合成核心。
- 先建立数据投影和兼容层，再拆分页面，避免 UI 与存储迁移同时落地造成难以回滚的问题。
- 文件迁移必须在前台可见、可恢复，并在空间不足时提前停止。
- 不自动操作用户未授权的目录。
- 所有批量操作必须精确作用于选中记录，不能通过作者昵称或目录名称推断。
- 保留现有预览播放器行为，包括单音频播放、视频控制层自动隐藏、全屏状态恢复和切换应用续播。

## 8. 验收标准

- 底部导航出现独立“本地下载”入口，任务页不再展示作者收藏列表。
- 下载完成后任务卡片消失，并能从提示或首页跳转到正确本地内容。
- 收藏作者的同时活动任务只显示一张作者卡片，速度与进度聚合正确。
- 未收藏作者任务保持独立，完成后进入独立作品。
- 收藏作者后，匹配的独立作品安全迁入作者目录；失败时原文件仍完整存在。
- 本地下载中的图片、视频、音频、Markdown 和评论预览功能保持可用。
- 文件被外部删除时记录置灰，重新下载和删除记录可用。
- 风控倒计时只在任务页顶部显示，卡片不重复显示倒计时。
- 已取得 CDN 地址的下载不因平台解析冷却而停在“准备下载”。
- 作者与独立作品均可按平台筛选。
- 无活动任务时没有无限进度动画。
