# X 单帖子媒体下载实施计划

对应设计：`docs/superpowers/specs/2026-09-06-x-single-post-support-design.md`

## 1. 平台基础能力

- 在 `SourcePlatform` 增加 X、主机识别、登录地址、品牌色和 Cookie 名。
- 更新所有穷举平台分支；作者目录明确排除 X，单任务平台筛选包含 X。
- 增加 X/Twitter 状态链接解析测试和旧平台回归测试。

## 2. 多附件数据模型

- 新增附件类型、`MediaAttachment` 和逐附件档位选择模型。
- 扩展 `ParseResult`、`TaskSpec` JSON 序列化，保证旧任务缺省兼容。
- 增加图片、视频、GIF、混合附件和旧 JSON 兼容测试。

## 3. X 解析器

- 实现 `XSourceResolver`，严格提取状态 ID 并生成规范链接。
- 实现匿名公开元数据、访客 GraphQL、登录 GraphQL 和页面快照的有限回退。
- 实现 `XMediaNormalizer`，处理 GraphQL 包装、转帖、引用帖边界、作者和附件。
- 图片构造最高可用候选；视频只接收直连 MP4 并保留全部档位；识别 HLS-only。
- 对接口响应使用脱敏固定样本测试，不把令牌或完整签名 URL写进仓库。

## 4. 首页解析与登录

- 将 X 接入现有解析状态机，匿名优先，认证错误才启动登录环境。
- 首页登录状态增加 X；登录 WebView 不启用抖音/小红书的视口注入与桌面模式。
- 为 X 提供固定登录入口、可滚动网页、缩放、键盘与返回历史行为。
- 登录完成后检测 `auth_token` 和 `ct0`，敏感值不记录。

## 5. 解析结果与逐附件设置

- 解析结果页按顺序展示附件摘要。
- 图片与 GIF 无需档位选择；普通视频逐附件保存所选 MP4 档位，默认最高。
- 视频处理模式只作用于普通视频，图片和 GIF 始终保存。
- 新增 X 作者昵称、`@用户名` 和任务文案显示测试。

## 6. 多附件下载

- `DownloadExecutor` 在附件列表非空时进入 X 多附件执行路径。
- 按顺序下载并识别真实图片扩展名；普通视频复用现有轨道处理；GIF 保留无声 MP4。
- 聚合速度、字节进度、输出文件和真实总大小；支持取消与中间输出持久化。
- 扩展重新下载预检和事务式替换，远端失败时保留旧输出。

## 7. 预览、分享与日志

- 验证混合 MIME 输出按顺序进入现有预览器，必要时只修正输出选择规则。
- X 任务复用分享、打开文件夹、删除、批量操作和平台筛选。
- 增加解析策略、附件统计、档位数量、限流与 HLS-only 日志；统一脱敏。

## 8. 文档与测试包

- 更新根 README、Android README 和支持平台表。
- 运行单元测试、Debug lint/编译和 APK 元数据检查。
- 构建不启用 R8、使用现有发布证书签名的可覆盖安装测试包并复制到共享目录。
- 测试阶段不推送正式 Release；真机样本通过后再准备 `1.7.0`。
