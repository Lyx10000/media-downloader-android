# 多平台下载器 1.8.0

本次更新将应用由“聚合下载器”正式更名为“多平台下载器”，GitHub 项目与 APK 也同步采用
`MultiPlatformDownloader` 命名。Android 包名和正式签名保持不变，可以覆盖升级并保留现有
任务、设置、下载记录和平台登录状态。

## 主要更新

- 新增独立的“本地下载”页面，分别管理独立作品与作者内容。
- 任务页面只保留下载中、等待、暂停、风控冷却及需要处理的失败任务；完成后自动转入本地下载。
- 同一收藏作者的活动下载会集中显示总体进度、当前速度和峰值速度。
- 独立作品和作者列表均支持按平台筛选。
- 作者卡片可以查看本地作品数量和占用空间。
- 本地独立作品、作者公开作品及作者本地作品新增发布时间。

## 内容归类与管理

- 单个作品下载时可以选择是否收藏作者。
- 已收藏作者的新作品直接保存至作者目录；收藏作者时会安全整理已有独立作品。
- 作者存在活动下载时暂时禁止修改收藏状态，避免下载目录冲突。
- 取消收藏但仍有本地作品的作者会进入本地归档，文件不会被删除。
- 统一作者与独立作品的筛选、批量删除、重新下载和文件缺失处理。

## 状态与稳定性

- 任务标题栏新增应用 CPU 负载和系统热状态提示。
- 修复总下载速度与任务实际速度不一致、传输结束后速度残留的问题。
- 改善音视频多轨任务的总体进度统计。
- 删除作品后会继续清理空的作品、作者和平台目录。
- 优化暂停、继续、删除、部分成功以及本地记录之间的状态同步。

## 升级说明

GitHub 仓库已由 `media-downloader-android` 更名为
`multi-platform-downloader-android`。GitHub 会自动重定向旧项目链接；如果旧版应用在本次
更名后的首次升级中无法自动选择 APK，请从新的 Releases 页面手动安装 1.8.0。升级到 1.8.0
后，后续版本可继续使用应用内更新。

本版本继续支持抖音、小红书、知乎、X、Instagram 和哔哩哔哩。平台实际可用内容仍受登录权限、
接口返回及风控状态影响。
