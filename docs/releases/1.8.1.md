# 多平台下载器 1.8.1

本次更新重点改善作者批量下载、本地内容管理和应用稳定性，同时完成 Android 内部架构拆分。
应用包名与正式签名保持不变，可以覆盖升级并保留已有任务、设置、下载记录和平台登录状态。

## 批量下载与风控处理

- 风控暂停后的作者批次现在可以在任务页继续、取消或重试，并提供更清晰的状态和操作入口。
- 新增批量工作负载准入控制：作者作品准备按批次串行执行，重型下载 Worker 的并发数量限制在安全范围内。
- 限制任务载荷内存缓存规模，降低大量历史任务在小内存设备上的资源压力。
- 保留已有的自适应传输并发机制；工作负载准入只限制任务启动阶段，不影响运行中的动态调节。

## 浏览与下载体验

- 修复作者列表离开后返回时滚动位置丢失的问题。
- 修复从作者本地作品打开预览或任务管理页后，返回时标签页和滚动位置丢失的问题。
- 改善短任务下载速度统计：按完整请求时间计算速度，并保留瞬时峰值。
- 完善本地下载筛选、批量操作、缺失文件处理和设备负载提示。

## 稳定性与维护性

- 将下载流程拆分为视频、图片、文档、附件、网络传输和输出发布等独立模块。
- 将抖音、小红书和知乎解析器拆分到各自的平台模块。
- 拆分首页、作者页和任务页的界面及工作流职责，减少大型文件之间的耦合。
- 补充工作负载并发、滚动位置、速度统计和平台状态持久化等自动化测试。

本版本继续支持抖音、小红书、知乎、X、Instagram 和哔哩哔哩。平台实际可用内容仍受登录权限、
接口返回及风控状态影响；小红书作者主页和批量下载暂不支持，单作品下载不受影响。
