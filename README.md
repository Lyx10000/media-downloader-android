# 多平台下载器

一款运行在 Android 手机上的多平台媒体下载工具，支持保存视频、图片、音频和图文内容，并提供作者作品管理与批量下载。

应用会优先选择当前能够获取的高质量资源，也支持用户手动选择清晰度。受平台接口、账号权限和作品状态影响，不保证能够取得作者上传前的原始文件。

## 下载与安装

[前往 GitHub Releases 下载最新版 APK](https://github.com/Lyx10000/multi-platform-downloader-android/releases/latest)

- 支持 Android 10 及以上系统。
- 当前提供 `arm64-v8a` 安装包。
- 使用本项目正式签名版本时，可以覆盖升级并保留应用数据。

## 主要功能

### 下载

- 从系统分享面板接收链接，也可以手动粘贴分享文本。
- 自动选择当前可获取的最高质量候选，视频支持手动选择清晰度。
- 支持视频轨、音频轨和合成视频分别保存。
- 支持仅保存视频、仅保存音频、保留分轨以及仅保存最终 MP4。
- 图片和视频按服务器返回内容保存，不主动降低画质或二次压缩。
- 支持后台下载，显示下载百分比、实时速度和文件大小。
- 下载失败、文件丢失或作品资源更新后，可以重新解析并下载。

### 作者与批量下载

- 支持通过作者主页链接建立作者库。
- 展示作者资料、公开作品和本地下载记录。
- 支持分页选择、全选当前页、批量下载、批量重试和批量删除。
- 下载前显示预计占用空间和设备剩余空间。
- 已下载作品会明确标注，远端作品被隐藏或删除不会自动删除本地文件。
- B站支持选择多 P 投稿中的全部分 P 或仅下载 P1。

### 任务与本地内容

- 任务页集中展示未完成下载、进度、速度及设备运行状态。
- 本地下载按独立作品和作者归档管理，并支持按平台筛选。
- 作者本地作品支持按下载时间、发布时间和文件大小排序。
- 支持单个或批量删除任务，并可选择是否同步删除下载文件。
- 支持打开任务文件夹和在应用内管理文件。

### 预览与分享

- 支持图片轮播与全屏预览。
- 支持视频和音频播放、暂停、拖动或点击进度条跳转。
- 同一时间只播放一个媒体，切换应用后可以恢复播放位置与显示状态。
- 支持多选并分享到 QQ、微信、邮件及其他兼容应用。
- 知乎图文保存为 Markdown，并在应用内显示已下载的图片和视频。

### 登录、日志与更新

- 首页显示各平台登录状态，并可打开对应登录环境。
- 登录信息仅保存在本机，用于访问账号有权限查看的公开内容。
- 内置脱敏诊断日志，方便定位下载失败和平台适配问题。
- 支持导出 ZIP 日志并通过系统分享面板发送。
- 支持检查 GitHub 新版本，并可选择镜像源加速下载。
- 更新需要用户手动确认，安装前会校验包名、版本号和签名。

## 使用方法

1. 复制作品链接或平台分享文本。
2. 打开应用并粘贴内容，点击开始解析。
3. 选择清晰度、保存模式和是否归档作者。
4. 开始下载，在任务页查看进度，在本地下载页管理文件。

需要批量下载时，可输入受支持平台的作者主页链接，收藏作者后选择公开作品下载。

## 注意事项

- 可下载内容和清晰度取决于平台当前返回结果、作品权限及账号状态。
- 私密、付费、会员专享、已删除或无权访问的内容可能无法下载。
- 频繁解析或批量请求可能触发平台风控，遇到提示后请等待一段时间再试。
- “最高质量”指本次能够获取的候选中质量最高的一项，不代表平台保存的绝对最高版本或作者母文件。
- 请遵守平台服务条款、内容版权和所在地法律，仅下载你有权保存的内容。
