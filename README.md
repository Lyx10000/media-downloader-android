# 抖音/小红书资源下载器

完全在 Android 手机本地运行，支持从抖音或小红书分享、手动粘贴、
全部可用清晰度、原图、四种音视频模式、后台下载和脱敏诊断日志。安装和构建方式见
[`android/README.md`](android/README.md)。

## 原理

应用通过隐藏的 WebView 登录环境获取并复用平台 Cookie，再由纯 Kotlin 解析器调用带
`a_bogus` 签名的
作品详情接口获取完整媒体档位。视频默认按分辨率、帧率和码率选择最高档，下载前
也可以手动选择其他清晰度。DASH 分离式视频通过 Android MediaExtractor/MediaMuxer
无损合并音视频；音视频已经封装在同一个 MP4 中时，也会无损拆轨，整个
过程都不会重新编码。选择清晰度后始终可以选择以下保存方式：

1. 视频轨 + 音频轨 + 合成视频，并保留全部三个文件（默认）
2. 只保存视频轨和音频轨，不合成
3. 只保存视频轨
4. 只保存音频轨

默认方式生成合成文件、视频轨和音频轨，合成成功或失败都不会删除原始分轨文件。

图文优先使用 `origin_url`，其次选择 `url_list` 中质量最高的无水印 CDN 地址，
文件按服务器返回内容原样保存，不转格式、不二次压缩。“最高档”指抖音当前接口
公开提供的最高质量版本，不保证等于作者上传前的母文件。
