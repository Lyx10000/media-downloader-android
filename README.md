# 多平台下载器

面向 Android 的多平台图片、视频和音频下载工具。应用会从平台当前返回的媒体候选中优先
选择质量更高的版本，也允许手动选择视频清晰度；平台未公开作者母版时，无法保证取得上传前
的原始文件。

## 下载与安装

[前往 GitHub Releases 下载最新版 APK](https://github.com/Lyx10000/multi-platform-downloader-android/releases/latest)

当前发布版为 **v1.8.0**。本版本将应用正式更名为“多平台下载器”，并重新整理任务队列与
本地内容管理。应用支持 Android 10 及以上系统，
仅提供 `arm64-v8a` 安装包。下载
Release 中的 ARM64 APK 后可直接侧载；使用官方 Release 中相同签名的旧版本时，可以覆盖安装并
保留任务、设置和 WebView 登录状态。

## 支持平台

| 平台 | 视频 | 图片/图文 | 独立音频 | 清晰度选择 |
| --- | --- | --- | --- | --- |
| 抖音 | 支持 | 支持，多图批量下载 | 支持 | 支持接口返回的全部档位 |
| 小红书 | 支持直连视频 | 支持，多图批量下载 | 暂不提供 | 支持页面返回的全部档位 |
| 知乎 | 支持独立视频及正文内嵌视频 | 支持文章、回答、想法，保存 Markdown 与媒体目录 | 暂不提供 | 独立视频可选档位；正文视频自动最高候选 |
| X | 支持单帖子直连 MP4 与 GIF | 支持单帖子原图及最多 4 个混合附件 | 视频内置音频可拆分 | 每个视频附件独立选择档位 |
| Instagram | Reel、单帖子直连 MP4 | 单帖子图片及混合附件 | 视频内置音频可拆分 | 每个视频附件选择接口返回的 MP4 档位 |
| B站 | 普通投稿视频，支持多P | 暂不提供 | 支持独立音轨 | 接口当前返回的 H.264/AAC DASH 档位 |

后续平台通过统一 Kotlin 解析器接口接入；支持范围不代表平台全部资源均可下载，具体限制见下文。

## 主要能力

- 从系统分享面板接收链接，或手动粘贴分享文本。
- 可按作者主页链接建立抖音、知乎、X、Instagram 和 B站作者库；X、Instagram 也支持准确的 `@用户名`，B站支持 UID 和个人空间分享短链。小红书仅保留单作品下载，不再提供作者批量下载。
- 批量下载前统一选择视频质量和音视频模式，显示粗略大小区间与保存位置剩余空间；已完整下载的作品会明确标注并在“全选当前页”时跳过。
- 作者资料、公开作品与“本地下载”统一展示；本地下载包含失败的准备记录，可批量重试或删除，正在传输的任务显示进度与速度。远端可访问状态和本地文件状态分别保存；作品被隐藏或删除不会连带删除本地文件。
- 作者批量任务先持久化再交给 WorkManager，应用退到后台或进程被回收后仍可恢复；遇到平台风控会暂停剩余作品供稍后继续。
- 视频按分辨率、帧率和码率排序，默认选择当前能够取得的最高候选。
- 图片保留所有可用候选，优先下载无明确水印标记、质量更高的地址，但不承诺自动去水印。
- 支持识别抖音和小红书实况照片，保留原图片与动态视频，并在 JPEG 静态源可用时额外生成 Motion Photo。
- X 支持单帖子图片、视频和 GIF 混合附件，按原顺序保存；转帖下载原帖媒体，引用帖只下载外层帖子自身媒体。
- 支持视频与音频分别保存、单独保存，以及无重新编码合成并保留原分轨。
- 支持“仅保存 MP4”：分离音视频轨会合成后仅保留成品；多视频帖子按每个视频分别生成 MP4。
- B站多P稿件按稿件分组，进入后管理各P；支持选择分P下载，作者批量下载可选择全部分P或仅P1。分离的音视频轨并行下载并分别显示进度，作者接口返回 IP 属地时一并展示。
- 后台下载显示真实百分比、速度和完成后的文件大小。
- 任务页显示可取得的抖音号、小红书号或知乎作者昵称，并支持一键复制。
- 任务页支持按平台筛选，并支持单个或批量重新解析下载；作者下载记录同样支持批量重下和删除。新内容完整落盘后才替换旧下载，失败或取消会保留原文件。
- 任务页支持图片轮播、音视频播放、多选分享和应用内文件管理。
- 支持默认公共下载目录和用户通过系统目录选择器指定的位置。
- 内置脱敏诊断日志，便于平台接口变化后继续适配。
- 设置页每日最多自动检查一次版本信息，只显示新版提示；更新下载和安装必须由用户手动触发。
- 更新支持 `gh-proxy.org` 镜像加速与 GitHub 原始源，安装前强制校验包名、版本号和签名证书。

安装、使用和构建说明见 [`android/README.md`](android/README.md)。

## 工作方式

应用通过 WebView 登录环境获取并复用平台 Cookie，再由纯 Kotlin 解析器在手机上请求作品
详情。抖音优先使用本地 Kotlin `a_bogus` 签名详情接口，并回退到 `iteminfo`、移动端 Feed、
分享页和作品页面；所有回退结果都严格核对作品 ID。小红书按已知状态路径查找目标笔记，失败时
执行有上限的深层扫描，并可使用 WebView 页面快照。知乎优先请求公开 JSON，并在必要时回退到
页面初始状态。解析和下载不依赖远程中转服务器。
首页会显示各平台是否检测到本机登录凭据，点击平台即可打开对应的全屏登录环境。凭据仅用于本机请求，不写入诊断日志；检测到凭据不代表凭据永久有效或一定不会触发风控。

重新下载会先尝试获取作品的最新详情。详情接口被风控拒绝、但任务保存的旧 CDN 地址仍然
有效时，应用可以回退到旧地址恢复文件；这种情况下无法补全旧任务缺失的作者账号，也无法
发现平台后来新增或调整的清晰度档位。

知乎文章、指定回答和想法会保存为 `article.md`、`answer.md` 或 `pin.md`，正文图片和知乎
内嵌视频保存在同任务的 `media/` 子目录并由 Markdown 以相对路径引用。在应用的任务文件管理中点击 Markdown，会用内置阅读器显示已下载的全部图片和视频；将整个任务目录复制到电脑后，相对路径仍然有效。只有问题、没有指定
回答的问题链接可进入问题归档，按批次继续下载可访问的回答及评论；盐选、付费、私密或无权访问内容不受支持。

X 首先读取公开帖子嵌入数据，必要时使用 X Web 会话补充。纯文本帖子不会创建下载任务；当前
只下载 X 自身托管的图片和直连 MP4，不递归下载外部站点，也暂不处理仅提供 HLS 的视频、Spaces
或直播内容。

X 作者入口读取目标作者的媒体列表，排除纯文字、转发和其他作者的推荐内容。作者访问需要先登录 X，不改变单条帖子的匿名优先解析路线。

Instagram 支持 `/reel/`、`/reels/`、`/p/`、`/tv/` 作品链接，通过页面状态、登录态媒体接口和
GraphQL 获取媒体，必要时读取 WebView 页面状态。支持作者帖子与 Reels 分页选择下载（Reels 列表需要登录），不包含 Stories、直播以及仅提供 DASH/HLS
的视频。最高档位指本次能获取的直连 MP4，并非上传原文件，也未承诺高于 DASH 分轨质量。
年龄、账号设置或私密权限限制的作品，需要用户在内置环境登录有查看权限的账号；网络限制与平台风控
仍可能导致失败。作者头像之外的简介、粉丝数等资料目前可能不完整，不影响已取得作品的下载。

B站支持 BV/av 视频链接、`b23.tv` 分享短链，以及 UID、个人空间链接查找作者。仅处理普通、
未加密的 H.264/AAC DASH 投稿视频；番剧、直播、动态和付费内容不在当前范围内。
可用清晰度受登录权限和接口返回限制，不承诺取得所有高码率或会员档位。作者接口未返回 IP 属地时不显示该字段。

DASH 分离式视频通过 Android `MediaExtractor` / `MediaMuxer` 合并音视频；音视频已经封装
在同一个 MP4 中时也可以拆轨，整个过程不重新编码。用户可以选择：

1. 视频轨 + 音频轨 + 合成视频，并保留全部三个文件（默认）
2. 只保存视频轨和音频轨，不合成
3. 只保存视频轨
4. 只保存音频轨
5. 仅保存 MP4（必要时合成，不保留中间分轨）

下载内容按服务器返回的字节原样保存，不主动转格式或二次压缩。“最高候选”仅指应用当前
能够解析到的资源中排序最高的一项，不代表平台保存的绝对最高版本或作者母文件。

## 隐私与权限

解析、下载、合成和日志均在手机本地完成。Cookie 保存在 Android WebView 的应用数据中，
诊断日志会脱敏 Cookie、签名和 URL 查询参数。应用不会上传下载记录。

诊断页仅展示最近日志的可读预览；点击“导出 ZIP”会将完整日志保存到
`Download/MultiPlatformDownloader/diagnostics/`，并打开系统分享面板。旧版本创建的
`Download/DouyinDownloader/` 仍可被识别和管理，不需要手动迁移。

普通下载使用 MediaStore 或系统目录授权；“所有文件访问”仅用于清理默认下载目录中的空
任务文件夹，不是普通下载的前置条件。

## 架构

项目是纯 Kotlin Android 应用，源码按职责分为四层：

- `app`：应用入口、依赖注入、页面导航与历史 Worker 兼容创建。
- `core`：统一数据模型、网络、数据库、下载基础设施、存储、设置、日志与更新。
- `platform`：抖音、小红书、知乎、X、Instagram 和 B站各自的解析与作者数据适配。
- `feature`：首页、任务、作者库、下载编排、预览、文件管理和知乎归档等用户功能。

Jetpack Compose 构建界面，Room 保存任务，WorkManager 执行后台下载与作者批次，Media3/Coil
提供预览。各平台解析结果先归一化为统一媒体和作者模型，再交给公共下载流程；新增平台通常
只需增加平台适配，不需要复制任务和下载框架。APK 不包含 Python、Chaquopy 或 ffmpeg。

源码命名空间已经统一为 `com.local.multiplatformdownloader`。为保证旧版可以覆盖升级并保留
Room 数据、设置和 WebView 登录状态，已发布应用的 Android `applicationId` 继续保留为
`com.local.douyindownloader`；这是刻意保留的兼容标识，不代表当前产品仍只支持抖音。
